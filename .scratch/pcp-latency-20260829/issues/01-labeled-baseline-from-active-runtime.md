# 01 — Собрать помеченный baseline из активной сборки

**What to build:** Воспроизводимый набор измерений P/CP из реально запущенного Stepler с корректной меткой окружения и агрегированным снимком производительности до любых изменений clipboard guard.

**Blocked by:** None.

**Status:** ready-for-agent

- [ ] Зафиксировать путь, версию и время сборки реально запущенного Stepler в артефакте измерений.
- [ ] Перед перезапуском активной сборки задать осмысленную метку окружения и убедиться, что новые события не имеют значения `unlabeled`.
- [ ] Собрать не менее 30 успешных warm и 5 cold операций для Web P без выделения и Web CP без выделения при неизменных остальных ключах серии.
- [ ] Сформировать snapshot без смешения версий, окружений, методов, веток алгоритма и без `RolledBackOrFailed` в целевой серии.
- [ ] Сохранить исходные события и итоговый snapshot так, чтобы их можно было сравнить с post-fix измерением.
