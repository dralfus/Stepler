# 04 — Принять решение по ускорению UIA на валидном baseline

**What to build:** Достаточные раздельные UIA-измерения и обоснованное решение, нужен ли долгоживущий UIA worker вместо запуска разовой операции.

**Blocked by:** 01 — Собрать помеченный baseline из активной сборки.

**Status:** ready-for-agent

- [ ] Собрать отдельные валидные warm и cold серии как минимум для Rocket.Chat editable и Sticky Notes document.
- [ ] Зафиксировать вклад захвата контекста, применения замены, проверки и переключения раскладки.
- [ ] Сопоставить выигрыш потенциального worker с рисками изоляции UIA, смены фокуса и отмены операции.
- [ ] Принять и документировать решение go/no-go; при no-go не менять UIA реализацию.
- [ ] При go подготовить отдельную ограниченную задачу с контрактами времени жизни, отмены и fallback, а не внедрять worker в этой задаче.
