# 07 — Выпустить подтверждённый отчёт оптимизации задержки

**What to build:** Единый отчёт, который доказывает результаты оптимизации и отделяет завершённые улучшения от сознательно отложенных решений.

**Blocked by:** 03 — Подтвердить ускорение WebKeyboard после исправления guard; 04 — Принять решение по ускорению UIA на валидном baseline; 05 — Измерить PSReadLine и выбрать точечное ускорение; 06 — Измерить Office и закрыть safety gate перед ускорением.

**Status:** ready-for-agent

- [ ] Для каждой измеренной поверхности указаны build, environment, число warm/cold операций, p50, p95, неуспехи и доминирующая фаза.
- [ ] Для WebKeyboard есть подтверждённое сравнение до/после и проверка сохранности буфера обмена.
- [ ] Для UIA, PSReadLine и Office есть либо подтверждённый выигрыш, либо обоснованное решение не менять реализацию.
- [ ] Нет регрессий в корректности замены, позиции курсора, переносах строк, форматировании и переключении раскладки.
- [ ] Итоговый документ содержит следующий шаг только для подтверждённого оставшегося bottleneck.
